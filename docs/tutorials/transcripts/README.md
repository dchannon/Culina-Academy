# Tutorial Transcripts

Store one Markdown transcript per published tutorial. Use a numeric prefix matching the tutorial order, for example:

```text
01-framework-overview.md
02-control-plane.md
03-orchestration-plane.md
```

Each transcript should contain:

```markdown
# VIDEO TITLE

**YouTube:** VIDEO URL  
**Published:** YYYY-MM-DD  
**Duration:** 00:00  
**Companion docs:** DOCUMENT LINKS

## Summary

TWO OR THREE SENTENCES.

## Transcript

### 00:00 - Introduction

TRANSCRIPT TEXT.

### 00:00 - TOPIC

TRANSCRIPT TEXT.

## Corrections And Version Notes

- YYYY-MM-DD: INITIAL PUBLICATION.
```

Transcripts improve accessibility, make video content searchable in GitHub, and provide a maintainable correction path when documentation changes.
