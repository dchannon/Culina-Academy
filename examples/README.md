# Example Catalog

Choose the example set that matches your task and contract format.

| Example set | Purpose | Compatibility |
| --- | --- | --- |
| [Current portable references](current/README.md) | Current file/API, transformation, service, and environment-neutral contract patterns | Follow each example's scope and the current field reference |
| [Complete sandbox metadata](metadata/data-culina-sandbox-test-client/README.md) | Trace relationships across jobs, sources, transformations, and dependencies | Original `2.2.0` sandbox export; inspect before adapting |
| [Compact V2 learning examples](config/sandbox-v2/README.md) | Small ingestion, transformation, dependency, and validation exercises | `culina.framework.config.v2.example`; validated by bundled teaching schemas |

The complete sandbox and compact teaching format are different shapes. Neither should be substituted for the current deployment package without review.

Use neutral examples as references, set environment values through your approved configuration, and keep credential values outside metadata. Start with [Configuration Guide](../docs/configuration/README.md), [Field Reference](../docs/reference/config-field-reference.md), and [Version Compatibility](../docs/reference/version-compatibility.md).
